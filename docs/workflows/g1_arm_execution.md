## 已实现接口

[arm_execution.py](https://github.com/Evan-XLiu/bimanual_tokenizer/blob/UnitreeG1/scripts/unitree_g1/arm_execution.py) 不导入或启动 DDS；由上层注入 `emit(Command)` 并调用伺服 `step(now)`。接口包括 `observe`、`read_observation`、`request_control`、`send_targets`、`stop` 和 `release_control`。

- 构造时不输出指令；接管要求新鲜反馈，首目标精确复制当前双臂 14 维实测 q，首帧增益为零。
- `ENGAGING` 保持这个参考姿态并线性增加增益，完成前拒收运动目标。
- `ACTIVE` 校验目标维度、有限值、关节范围和时间，限制目标速度与加速度；目标反向时允许受限的减速距离，不能把它当作碰撞保护。
- 正常停止/退出冻结最后指令位置并逐步把增益降为零，不回零，不恢复 ai 服务。该卸载路径已用于有限人工托持试验，卸载时可发生重力位移；无人托持与更广泛故障情形未验收。
- 状态或目标过期、tick 回退、反馈偏差、机型字段变化和伺服超时触发卸载并锁存故障；恢复输入不会自动接管。重复 tick 不刷新状态有效期。
- 发布失败直接锁存故障，不能声称卸载指令已送达。进程被杀、网络中断时软件不能保证停止，硬件看门狗及现场停止方式仍待验证。

`encode_debug_command` 仅构造候选 **全身** `LowCmd` 并计算 CRC：索引 15–28 有双臂位置/增益，其余槽位零增益、零速度、零前馈力矩。**这不保持原腰腿控制器**，也不是能在 ai 运行时直接发送的双臂覆盖命令。有限真机入口为下述 hold_arms.py；候选增益/限位保存在版本化 profile 中，单元测试的合成数值不能用于真机。

有限时长原姿态保持入口已补齐，见下节；仍缺经过核验的硬件 profile、碰撞约束、Quest 接入及现场接管/退出验收。不能把该入口称为已验收的真机遥操作器。

## 原姿态保持入口与退出联锁

[hold_arms.py](https://github.com/Evan-XLiu/bimanual_tokenizer/blob/UnitreeG1/scripts/unitree_g1/hold_arms.py) 默认只读影子模式；正常执行路径仅在显式 `--execute` 且 profile 包含硬件验证证据时才创建 `rt/lowcmd` 发布器；另有下述用户授权的 `--candidate-trial` 有限实验路径。正常路径的 profile 中关节映射、增益/限位、躯干支撑、手臂卸载支撑、独立停止手段和退出行为的证据必须非空；这些字段是人工审核记录，不是自动安全认证。

启动先连续检查新鲜状态、静止条件、调试模式及指令话题。发布循环使用反馈初始化目标，保持原姿态，不接收 Quest、外部轨迹或夹爪目标。Ctrl-C/SIGTERM 只请求卸载，不直接中断发布；正常结束及一般异常均尝试冻结最后目标、逐步降增益，末尾连续发送零增益帧，再销毁发布器，不开启 ai_sport。磁盘日志失败后仍尝试卸载。

运动服务查询在独立线程进行，周期约 0.2 秒、RPC 超时 0.5 秒、结果时效 0.8 秒，不阻塞伺服。调试模式失去确认或发现其他发布者的有效指令时，立即停止本进程发布，避免与重新启动的控制器竞争；此时报告卸载未确认，不能把停止发布等同于物理停止。DDS 原始读取器用 publication handle 区分本进程和其他指令来源；该身份检查已在回环网卡、独立 domain 213、非机器人话题下测试。端点存在但不发消息不触发拦截；这不是硬件级独占锁。

`summary.json` 的 `unload_submitted` 只表示候选卸载消息已提交到 DDS；**不表示机器人已执行**。`physical_unload_verified` 始终为 false，须依靠现场观察与实际反馈另行验收。SIGKILL、主机掉电、网络断开、线程卡死不受 Python finally 保证，不能替代机器人端看门狗和现场停止措施。

## 2026-10-08 边界插值制动修正

005 的 `trajectory_limit` 后，离线用归档 IK 目标按合成 10 ms 周期回放，旧算法在约 8.15 秒重现左肘初态下边界越界。该回放不是精确现场时序重演。

修正为在每步选择速度时同时满足 `u*dt + u²/(2*a) <= 剩余距离`，并将上下关节边界允许的速度区间与速度/加速度区间取交集。目标自身也使用包含本步位移的制动速度，避免静态边界目标过冲；突然反向时仍受加速度限制，不瞬间清零速度。无可行交集仍触发 `trajectory_limit`，不裁剪位置掩盖不可行状态，不放宽原限位。

完整 57 项离线测试通过，包括旧算法失败复现、10 分钟模拟周期抖动/反向/双边界，以及不可行状态故障；005 目标循环回放 60 秒无越界，最大速度 0.05 rad/s、加速度 0.1 rad/s²。见 [离线制动复核](../../artifacts/unitree_g1/braking_review_20261008.json)。真机后续结果见 Quest 工作流。
